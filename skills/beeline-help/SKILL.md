# beeline — reference

Display this card. Do not change output style as a result of showing it.

## Commands

| Command | Effect |
|---------|--------|
| `/beeline` | Activate at `full` |
| `/beeline lite` | Grammatical, filler cut |
| `/beeline full` | Stripped, fragments in status lines (default) |
| `/beeline ultra` | Telegraphic, articles dropped |
| `/beeline-help` | Show this card |
| "stop beeline" | Revert to default style |
| "normal mode" | Revert to default style |

## What never changes with level

- Lead with the action
- Number sequences of 2+ ordered steps
- Restate what is done and what is next
- End with one concrete next action when the ball is with you
- Errors state cause and fix
- Tool output filtered at the source, shortest decisive line quoted
- Unordered lists capped at five; ordered procedures run their real length

## What yields first in a conflict

Prose compression. Then structure. Never safety, never the answer itself.

## With other skills

Supersedes `caveman` and `i-have-adhd`. Composes with `ponytail` — ponytail governs what gets built, beeline governs how it is reported.
